# 译流 · LingoRelay

一个支持本地 LM Studio、OpenAI 兼容在线接口和 Codex 账号授权的 Chrome 网页划词翻译扩展。

## 功能

- 框选网页文本后，通过右键菜单翻译
- 框选后按 `Ctrl+Shift+Y` 快捷键翻译，适用于屏蔽右键的网页
- 按 `Ctrl+Shift+U` 进入截图框选模式，使用视觉模型识别并翻译图片文字
- 新增、命名、保存和删除多套模型连接方案，分别选择优先与备用方案
- 支持 OpenAI 兼容的 Chat Completions / Responses API、自定义地址和 API Key
- 纯插件设备码登录 ChatGPT / Codex，使用订阅配额（实验性兼容接入，无需 Codex、Node.js 或辅助组件）
- 可选：优先方案网络失败或服务报错时自动切换备用方案，并显示主方案错误（默认关闭）
- 完整模型下拉列表，也支持手动填写模型 ID
- 内置全语言翻中、中翻英、日翻中方案
- 新增、编辑和保存自定义翻译提示词方案
- 设置默认方案，并在翻译结果中临时切换其它方案重译
- 网页内浮层展示结果并支持复制
- 本地保存最近 200 条翻译记录
- 支持复制、单条删除和全部清空历史
- 每次翻译均为独立请求，不读取或发送历史记录

## 安装

1. 使用 Chrome 120+，打开 `chrome://extensions`，开启右上角的“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本项目目录，或将发布 ZIP 解压后选择解压目录。
3. 打开扩展设置，选择本地、在线 API 或下述 ChatGPT / Codex 订阅服务。
4. 如用本地模型，先在 LM Studio 中加载模型，并在 Developer 页面启动服务器（默认端口 `1234`）。仅使用订阅或在线 API 时不需要 LM Studio。
5. 刷新模型、选择优先服务商和模型，然后保存设置。

已有安装：在扩展管理页点击重新加载，然后重新打开设置页。原来的 LM Studio 地址和模型会迁移为第一服务商，提示词和历史保留，自动在线备用不会自行开启。

## 连接方案与自动备用

1. 在设置页“编辑连接方案”中选择已有方案，或点击“＋ 新增方案”，填写便于区分的方案名称。原来的两套服务会保留，不影响已有订阅登录。
2. 本地服务选择“本地 LM Studio”。在线服务选择“OpenAI 兼容接口”，填写 API 基础地址、API Key 和模型 ID。
3. 接口协议默认使用 Chat Completions；只支持 Responses 的服务请选择 Responses API。地址填写到 `/v1` 或网关指定基础路径，不要附加 `/chat/completions` 或 `/responses`。
4. 点击“刷新模型”，从完整下拉列表中选择模型，或在下方手动填写 ID；已有 ID 不会过滤掉其它候选模型。列表连接成功不等于推理成功。
5. 点击“保存当前方案”将正在编辑的连接保存到浏览器。此按钮不改动提示词、其它方案或尚未保存的优先 / 备用选择。
6. 分别选择“优先方案”和“备用方案”，点击底部“保存设置”。删除连接方案同样在底部保存后生效，至少保留一套方案。不设置固定翻译总超时。

需要自动备用时，勾选“优先方案网络失败或服务报错时，自动使用备用方案”。本地、在线 API、订阅方案均可互为备用，优先与备用不能是同一方案。连接失败、实际网络超时、中断、非成功 HTTP 状态（包括 400/401/403/404/413/429/5xx）或生成错误会触发一次切换。不再在翻译前用短时限模型列表探测推断模型离线；浏览器站点权限未授予、连接设置未填等本地配置问题仍直接提示修正。

每次翻译最多调用指定备用方案一次，下一次仍从优先方案开始。切换发生时立即显示主方案的错误原因和备用方案名称；成功结果保留错误提醒，历史记录也保留脱敏错误；备用失败则同时显示两次错误。未勾选时不向备用发送内容。

### 长文本和长时间思考

翻译不设固定总时限，也不以“多久没出字”判断失败。本地和 OpenAI 兼容接口请求流式响应，订阅同样使用流式响应；兼容接口若返回完整 JSON 也能读取。思考事件和心跳不会被误当成译文或成功完成；必须收到完整结束信号才保存结果。等待期间保持后台活跃，避免普通空闲休眠导致请求中断。使用的是 [OpenAI Docs 的流式响应格式](https://developers.openai.com/api/docs/guides/streaming-responses)。仅登录、设备码轮询和设置页模型列表等管理请求仍有有限网络等待，不限制翻译生成时间。

服务器、代理和浏览器仍可能关闭连接或返回超时错误，插件无法取消这些外部限制。发生这种真实失败时按开关切换，而不是把模型“想得慢”判为错误。没有任何数据或错误返回时，客户端无法可靠区分正在思考和卡死，会继续等待，不凭空判断断网。若主、备都因为文本超出上下文或服务端生成时限失败，需拆分文本、选择支持更大上下文的模型，或调整自己管理的模型服务 / 代理限制；不自动截断原文，不把半截译文保存为成功。远端断线后仍可能已消耗额度；备用请求也可能产生费用。

开启自动备用意味着本次选中文字或裁剪截图可能发送到在线服务。截图翻译要求对应模型支持图片输入。所有服务均不要求安装插件辅助组件。

## ChatGPT / Codex 订阅登录（纯插件）

此版本直接由扩展后台完成设备码授权、凭据刷新、模型列表与翻译请求。无需本机端口、Codex、Node.js、扩展 ID 注册或中转服务器。支持 Chrome 的设备即可安装插件；换电脑后重新登录，不复制旧电脑凭据。

1. 在 `chrome://extensions` 重新加载插件，关闭旧设置页并重新打开。本版本删除 `nativeMessaging` 权限，增加用于恢复授权轮询的 `alarms` 权限。
2. 选择服务类型“ChatGPT / Codex 订阅”，点击“登录 ChatGPT / Codex”，同意访问 `auth.openai.com` 与 `chatgpt.com`。
3. 插件显示一次性设备码，并打开 `https://auth.openai.com/codex/device`。在官方页面登录、输入插件显示的设备码并确认。只确认自己发起的登录，不分享设备码。
4. 若官方页面要求开启设备码登录，在 ChatGPT 设置 → 安全中自行启用；受管理账号可能需要管理员允许。参见 [official OpenAI documentation：认证与设备码登录](https://learn.chatgpt.com/docs/auth)。
5. 返回插件，登录状态和模型列表会自动更新。选择模型、优先服务商并保存。模型列表失败时可刷新或手动填写账号可用的模型 ID。

设备码约 15 分钟有效；可取消、重新申请或更换账号。关闭设置页后后台仍会等待，浏览器暂停或系统休眠可能延迟检查；过期后需重试。已完成登录的凭据保留在本机并按需刷新。重新登录失败不会清除原有有效登录。所有订阅连接方案共享同一账号，可选择不同模型。

### 接入边界

- **实验性 Codex 兼容协议，不是官方 Chrome 产品，也不是保证可用于任意第三方产品的通用订阅 API。** 使用公开客户端的设备码流程；官方可能改变接口、限制客户端或账号访问。不能以本实现推断已获商业分发或应用商店审核许可，正式发布前需重新核对官方支持范围和条款。
- 只使用账号实际允许的 Codex 模型与订阅额度，不承诺所有 OpenAI 模型。模型目录成功也不代表推理一定可用；截图需要视觉模型。
- 订阅请求只发送至固定官方站点，不使用 ChatGPT 网页 Cookie、不读取已有 Codex 登录文件、不把订阅凭据发到自定义 API 地址。不伪装浏览器 User-Agent，不绕过服务端限制。
- 遇到权限、额度或客户端限制会显示主方案错误；只有明确启用自动备用时才转到指定备用方案，不会轮询所有连接或无限重试。如果指定的是付费 API，其调用可能产生费用。
- “退出本机登录”清除插件凭据并停止本插件的登录轮询；不退出 ChatGPT 网站，也不等于撤销服务端已签发的授权。

### 从旧辅助组件迁移

重新加载后插件不再连接任何辅助组件，也不复制旧组件的账号凭据，请在插件中重新登录。LM Studio、API 设置、提示词和历史保留；旧桥接密钥在保存设置时移除。

公开源码与发布 ZIP 均不包含旧辅助组件。以前安装过辅助组件的用户可按原版卸载说明解除注册；纯插件模式不要求先卸载，也不会删除旧授权数据。

每次翻译只发送本次输入与提示词，设置 `store:false`，不带 `previous_response_id`、会话历史或工具。订阅流式响应必须完整结束才算翻译成功，断流不保存半截译文。

## 使用

在普通网页中框选文字，然后：

- 按 `Ctrl+Shift+Y` 直接翻译；或
- 点击右键，选择“使用译流翻译”。

译文会显示在选区附近；点击扩展图标可以查看和删除历史。可前往 `chrome://extensions/shortcuts` 修改快捷键。

右键菜单和文本翻译快捷键始终使用设置页中选定的默认方案。翻译完成后，可点击结果浮层中的“其它方案”，使用同一段原文临时选择其它提示词重新翻译；这不会修改默认方案。

需要识别网页图片或无法选中的文字时，按 `Ctrl+Shift+U`，拖动框选屏幕区域。扩展只将裁剪后的截图发送给所选模型，要求该模型支持视觉输入。截图原图不会保存到历史记录。

## 请求与隐私

Chat Completions 翻译请求只包含两条消息（Responses 和订阅接入将同样内容映射为 instructions + input，并设置 store:false）：

```text
system: 设置页中的翻译提示词
user: 本次选中的文字
```

截图识别请求同样只有两条消息：

```text
system: 设置页中的翻译提示词
user: 截图识别提示词 + 本次裁剪后的图片
```

历史记录只写入 `chrome.storage.local`，不会被读取到模型请求中。截图历史只保存文字结果，不保存截图原图。扩展默认访问 `http://127.0.0.1/*` 和 `http://localhost/*`；如果使用其他地址，会在设置页由 Chrome 请求对应站点权限。

在线服务的 API Key 和订阅凭据仅保存在 Chrome 本地存储中（不是 chrome.storage.sync），不写入翻译历史，不发送给内容脚本。存储访问限制为 TRUSTED_CONTEXTS；设置页只收到脱敏登录状态与临时设备码，不收到 token。此存储不是加密保险库，应保护浏览器用户目录，不分享插件存储备份。在线服务会接收当前输入，其服务端数据保留规则由服务商决定。“不读取历史”不代表在线服务不会保留请求。

## 打包分发

Windows 开发者可运行（仅打包时使用 PowerShell，用户使用插件不需要）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

生成 `dist/lingo-relay-1.3.1.zip`，使用明确文件白名单，不包含旧辅助组件、测试、Git 信息、凭据或开发缓存。解压后在 Chrome 加载即可；升级现有安装建议在原目录重新加载，切换目录可能产生新的扩展 ID 和独立存储。

## 自动化检查

```powershell
node --test tests/*.test.*
```

测试使用模拟模型响应，不消耗在线额度。真实的账号登录、在线推理与浏览器交互需要在你的配置下验证。
